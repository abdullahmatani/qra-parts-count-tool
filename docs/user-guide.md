# QRA Parts Count Tool — user guide

The user documentation is a set of short articles in [`docs/help/`](help/). The same articles are
built into the app: press `F1`, or click **?** in the header, to read and search them offline.

New to the app? Take the **guided tour** from the start screen: it walks through one complete parts
count on a practice project.

## Articles

1. [Getting started](help/getting-started.md): what the app does, what you need, the workflow and
   the workspace.
2. [Guided tour and sample project](help/guided-tour.md): learn the app on a practice project.
3. [Projects and the working directory](help/projects.md): create and open projects, saving,
   backups and project settings.
4. [Importing and managing drawings](help/drawings.md): PDF, DWG and DXF import, names, the drawing
   register and new revisions.
5. [Viewing drawings](help/viewing-drawings.md): tabs, zoom and pan, find text, split view and CAD
   layers.
6. [Segments and ESDVs](help/segments.md): segments, process data, ESDVs, end flanges, split, merge
   and status.
7. [Highlighting and auto trace](help/highlighting.md): the Highlighter, auto trace, the Eraser,
   dashed zones and how equipment follows the highlighting.
8. [The equipment library](help/equipment-library.md): equipment types, size bins and datasets.
9. [Counting parts](help/counting.md): the count stage, the equipment bar, Stamp, Find similar
   symbols, warnings and the count table.
10. [Notes and drawing links](help/notes-and-links.md): segment notes, drawing links and link
    suggestions.
11. [Mapping the Excel template](help/excel-template.md): the template mapper and the A2.1 parts
    count sheet.
12. [Checking and exporting](help/export.md): the pre-export check, the outputs and the export log.
13. [Checking and handing over](help/checking-and-handover.md): checker workflow, project .zip and
    Firefox/Safari.
14. [Settings](help/settings.md): preferences, project settings and About.
15. [Keyboard shortcuts](help/keyboard-shortcuts.md): every key, on one sheet.
16. [Troubleshooting and FAQ](help/troubleshooting.md): what to do when something does not work.
17. [Glossary](help/glossary.md): the terms used in the app.
