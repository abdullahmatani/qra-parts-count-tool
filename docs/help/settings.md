# Settings

Click the cog at the top right (or **Settings** at the bottom of the start screen). Settings has
three tabs.

## General

These preferences belong to you and this browser, not to the project:

| Setting                                     | What it does                                                                                                                                     |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Theme                                       | **System**, **Light** or **Dark**                                                                                                                |
| Table density                               | **Compact** or **Comfortable** rows in tables                                                                                                    |
| DWG and DXF drawings                        | **Monochrome, like a plot** or **CAD colours**                                                                                                   |
| Your initials                               | Stamped on the notes you write, so checkers' comments stay separate                                                                              |
| Assign equipment to the highlighted segment | Equipment placed on a segment's highlighting goes to that segment instead of the active one (see [Highlighting and auto trace](highlighting.md)) |
| Name drawings after their files             | Imported drawings take the name of their file; turn off to read the drawing number and sheet from the title block                                |

## Project

The settings of the open project: its name and details, the counting rules, the units and the PDF
file name pattern. See [Projects and the working directory](projects.md#project-settings). Click
**Apply changes**.

## About

The version of the app, how it handles your data and works offline, and its licence:

- **Privacy**: no project data leaves the browser. The app sends no telemetry, analytics or error
  reports, and after loading makes no network requests other than fetching its own files.
- **Browser storage**: only interface preferences and the list of recent project folders are
  stored in the browser. Project data lives in the working directory.
- **Licence**: the QRA Parts Count Tool is free software under the GNU General Public License,
  version 3 or later. The tab links to the source code, the licence and the licences of the
  components it includes. The licence covers the program, not your work: drawings, counts and
